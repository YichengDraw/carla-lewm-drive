D1 任务定义

阶段场景规则通过含义
D1-A Town03，白天，干路面，无车，无行人，绿灯，6 个固定 spawn route。 500m cap；collision/off-road/blocked 立即停表；speed-limit 只记软惩罚；覆盖自然直行、弯道、路口左/右转。 模型能在城市道路视觉分布上保持车道和路边安全。
D1-B 同 D1-A，真实交通灯。 red-light violation 停表；speed-limit 继续软惩罚。 模型开始体现交通规则，而不是只沿路走。
D2 稀疏车辆，固定 traffic seed；或 D1-C route-command setting。 加入车车碰撞、前车交互，以及带 change_lane_left/right 命令标签的变道。 只有 D1 稳定且 route command 标签可用后再进入。
左右转应该在 D1-A 就覆盖，因为路口和弯道有明确道路几何目标。变道暂时不放进第一轮，因为无车、无导航命令时，模型没有唯一的“何时变道”目标；先把 stay-in-lane 和自然转向做实，再加命令化变道。

优先级指标配置/解释
1mean_infraction_free_distance_mD1-A 中 speed 不计入 first infraction；主看碰撞、离路、blocked 之前的距离。
1success_rate_no_primary_safety_infraction没有 collision、off-road、blocked 的 episode 比例。
2success_rate_no_primary_or_red_infractionD1-B 主指标：没有 collision、off-road、red-light、blocked。
3speed_limit_count速度规则违规次数，保留为可解释惩罚。
3mean_mini_driving_score路线完成度乘所有违规惩罚，用于防止完全忽略速度。
实现更新：评估器支持 speed_limit_as_infraction: false，并新增 stop_on_offroad / stop_on_red_light。D1-A 会把速度从停表条件降级为软日志。

Aux 决策

主 baseline
pred_loss + sigreg + action BC。这保留 LeWM latent prediction 的核心，配置中 use_aux_head: false，不实例化也不计算 aux/pred_aux。
消融 baseline
pred_loss + sigreg + action BC + aux + pred_aux。只有闭环指标赢，才把它作为驾驶 adapter 报告。

判断：你对 aux 的质疑是成立的。V-JEPA/LeWM 这条线强调少监督和 latent dynamics，额外往 latent 上读车辆状态会把故事变成工程增强。下一组先跑 no-aux，aux 只作为对照。

Go / No-Go

Continue
D1 数据 strict QC 通过；contact sheet 逐帧样本显示真实沿路行驶；no-aux W&B 从启动开始记录；D1-A Safety IFD 明显超过旧的 25m 边界。
Pause
某些 spawn route 反复被 QC 拒绝；lane offset 随距离单调变大；速度软惩罚很多但安全距离提高，需要先分析 trace 再改损失。
Stop
CARLA timing guard 报外部 tick；W&B 缺失；no-aux 和 aux 都在 50m 内出现 primary safety failure。
Scale
D1-A 成功后先跑多天气混训；tiny 在多 route / 多天气上稳定但明显受表示能力限制时，再跑 ViT small。

名词速查

Term解释
Safety IFD安全优先的 infraction-free distance；D1-A 中不因普通超速提前停表。
primary safety failurecollision、off-road / roadside departure、blocked。
red-lightD1-B 开启真实信号灯后纳入 hard failure。
speed soft penalty速度违规计数和扣分，但不主导第一轮 D1 安全距离。
aux从当前 latent 读车辆速度、路程、车道偏移等状态的辅助头；下一组只做消融。
pred_aux从预测 latent 读同一批状态；旧 D0 曾用于让预测 latent 更贴近控制变量。
action BC从 latent 预测专家动作块，用于直接闭环控制。
W&BWeights & Biases；所有认真训练从 process start 开始在线记录。
D1-W无车、绿灯、同 routes 的多天气鲁棒性阶段；只在 D1-A 有闭环信号后启动。
