名词速查

Term解释
CARLA自动驾驶仿真器，用来生成相机、车辆控制、车道、碰撞和红灯事件数据。
LeWMLeWorldModel，端到端从图像学习 latent dynamics 的世界模型。
ViT tiny / small / base视觉 Transformer 编码器大小；tiny 是主线，small 是 capacity 失败后的升级。
W&BWeights & Biases，用于训练曲线、验证指标、视频和配置记录。
QCQuality Control，逐帧检查数据是否缺帧、空白、动作异常或事件标签不可信。
closed-loop eval模型真实控制 CARLA 车辆，不只是离线 loss。
Infraction-Free Distance首次碰撞、离路、闯红灯、停死前的行驶距离，单位米。
Mini Driving Score路线完成度乘以违规惩罚，借鉴 CARLA Leaderboard 的评估思路。
D0 / D1 / D2D0 单车低速白天；D1 低密交通；D2 held-out 路线/随机种子。
CEMCross-Entropy Method，采样多条动作序列并选择低 cost 的规划器。

实验名解码

d0_tiny_h3_fs5：D0 简化场景、ViT tiny、3 帧历史、每 5 个 CARLA 原始帧合成一个模型动作步。

片段含义
d0单车、白天、干燥、低速路线。
tiny最小 ViT 主线，优先证明小模型是否能学。
h3模型输入 3 个历史视觉状态。
fs5CARLA 20Hz 原始控制每 5 帧合并，模型步长约 0.25s。

阶段计划

Phase 0：环境和仓库门控 current

目标：确认独立 GitHub repo、CARLA 0.9.16、Python API、W&B、5090、磁盘和配置路径。

退出条件：carla-lewm-build-html、carla-lewm-qc --help、carla-lewm-train --help 可运行；远端 5090 和 W&B 状态被记录。

Phase 1：D0-smoke 采集和逐帧 QC gate

目标：采 20 条 30 秒单车路线，生成 HDF5、recorder log、contact sheet、逐帧 QC JSON。

退出条件：0 hard QC issue、expert hard infraction 接近 0、人工逐帧抽查能确认画面/动作/事件标签一致。

Phase 2：batch sweep 和 tiny smoke planned

目标：按 256 -> 192 -> 128 -> 96 -> 64 找到最大稳定 batch，确认 5090 没有明显浪费。

退出条件：batch probe 写入 JSON，tiny smoke 有下降的 train/val loss，W&B 曲线和本地 CSV 同步存在。

Phase 3：tiny 主训练和闭环选择 planned

目标：每 5 epoch 做验证，按 closed-loop Infraction-Free Distance 选 best checkpoint。

退出条件：held-out D0 median 距离达到 300m 或失败原因被归类为数据、cost、planner、capacity。

Phase 4：small 升级门控 conditional

目标：只有 tiny 显示 capacity-limited 时，使用同协议训练 small。

退出条件：small 在相同 D0 manifest 上带来稳定闭环提升，否则停止扩大模型。

Phase 5：D1 低密交通 conditional

目标：加入少量车辆、无行人、保持低速，检查模型是否维持长程安全。

退出条件：报告 per-km infractions、路线完成度和失败视频。

指标

指标定义读法
Infraction-Free Distance首次 hard infraction 前累计米数，cap 为路线长度。越高越好，是主指标。
Mini Driving Score路线完成百分比乘 collision/offroad/red-light/blocked 惩罚。越高越好，防止只停车不撞。
val/pred_loss预测下一 latent 的 MSE。越低越好，但不能单独证明能开车。
QC hard issues缺 key、缺帧、空白帧、非有限 action 等硬错误。必须为 0 才进入训练。

Go / No-Go

Continue
QC hard issues 为 0，tiny 离线 loss 下降，expert baseline 正常，held-out D0 闭环距离持续提升。
Pause
训练 loss 下降但 closed-loop 无提升，优先查 cost 和 planner，不直接扩大模型。
Stop
数据逐帧异常、W&B 未启动、评估 manifest 不一致、或 CARLA expert baseline 本身失败。
Scale
tiny 通过所有 sanity 但明显 capacity-limited 时，才跑 small；base 不作为主线。
