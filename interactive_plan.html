阶段计划

Phase 1: 横向闭环修复

目标：让模型在 100m gate 上不再 10-20m 内离路。退出条件是 5/5 到达 100m 且 trace 中 predicted lane/heading 与 corrective steering 方向一致。

当前动作：训练 controlsign 配置；训练后先跑离线 tail diagnostic，再跑 100m gate。

Phase 2: 1km no-traffic / green-light

目标：在五条控制器验证路线跑满 1km。退出条件是 mean_infraction_free_distance_m = 1000m 且 5/5 primary safety success。

Phase 3: 红绿灯

目标：取消 force_green_lights，让 red-light violation 成为硬失败。只有 Phase 2 通过后进入。

Phase 4: 多天气与更大 ViT

目标：验证视觉鲁棒性或容量瓶颈。只有单天气 1km 有稳定成功后，混训天气和 ViT small/base 才有解释价值。

名词速查

Term解释
LeWMlatent world model，用图像 latent 和动作预测未来 latent。
ViT tiny当前小模型视觉编码器，参数和显存都较小，适合先验证任务定义。
cls_mean把 ViT 的 CLS token 和 patch token 平均池化拼接，给 lane 几何更多空间信息。
aux从当前图像 latent 读出 speed/lane/heading 等状态的辅助头。
pred_aux从预测未来 latent 读出下一步状态，直接服务 rollout lane-keep。
controlsign新增 loss：由预测 lane/heading 算出的 steering 必须与 teacher steering 同方向。
appliednext把闭环 eval trace 中下一行实际 applied action 作为当前状态的动作标签，避免 teacher/action 与真实转移不匹配。
tailgate针对失败尾部分布的训练和筛选策略；当前配置大量重复失败帧，并按 validation checkpoint 做 failure-tail 排名。
thr002低 active threshold 备选配置，把 control-sign loss 的有效 steering 门槛从 0.08 降到 0.02，用来覆盖小但持续累积的偏移。
lane invasionCARLA 车道线侵入传感器；现在作为 primary safety failure 记录和可选停止条件。
DAgger把模型闭环失败时遇到的状态重新用 teacher 标注，再加入训练，修补分布偏移。
IFDinfraction-free distance，首次硬违规前行驶的距离。
W&BWeights & Biases，用于在线记录 loss、验证指标、run 链接和配置。
